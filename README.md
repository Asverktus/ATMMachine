# ATM Machine

## Постановка задачи

Разработать консольное приложение на C# для симуляции работы банкомата. Приложение должно позволять пользователю выполнять базовые банковские операции: внесение, снятие и перевод средств, а также проверку баланса.

## Используемый паттерн

**Паттерн: Singleton**

### Цель применения

Паттерн Singleton гарантирует, что в системе существует **только один экземпляр** класса банкомата. Это критически важно для:
- централизованного управления состоянием банкомата
- обеспечения целостности операций (отсутствие "двух банкоматов", которые могли бы конфликтовать)
- единой точки доступа к функциональности банкомата

### Какую задачу решает

Проблема: если бы класс банкомата не был Singleton, при создании нескольких экземпляров могли бы возникнуть рассинхронизация данных о счетах и некорректные операции. Singleton гарантирует, что все операции работают с одним и тем же состоянием.

## Функциональные требования

- Вход в счет пользователя
- Пополнение счёта
- Снятие средств (с проверкой достаточности баланса)
- Перевод средств между пользователями
- Проверка баланса
